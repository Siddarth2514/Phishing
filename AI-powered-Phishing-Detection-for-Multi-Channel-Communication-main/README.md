# AI-Powered Phishing Detection System

An intelligent system to detect phishing attempts across emails, SMS, and chat platforms using machine learning and NLP techniques.

## Features
- Multi-channel phishing detection (Email, SMS, Chat)
- Content analysis using NLP
- Metadata analysis
- Link behavior analysis
- Real-time alerts
- Machine learning model for pattern recognition

## Components
1. Data Preprocessor
2. Feature Extractor
3. Machine Learning Model
4. Alert System
5. Multi-channel Integrations

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```python
python main.py
```
